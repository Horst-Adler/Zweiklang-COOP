# Alpha.34 — native start-menu artwork

Optional Union/Ninja menu artwork with Orebound Co-op at the top, a transparent inner main-menu background and unchanged original Gothic II logos. See [design, build and acceptance](MENU-ARTWORK.md).

Validation: 4,735 technical assertions; native full-screen/inner-window and texture-reference ABI checks; opaque BC1 mip colors checked against an independent DDS decoder; unique VDF entry mounted/read back; optional/source-only installation, retained settings, language-independent content ID, rejection of corrupted artwork, and failed-install rollback including removal of a newly added archive.

The game was not launched. Native Ninja parsing, renderer appearance, selection changes and submenu navigation remain open. No campaign, inventory, combat, character or save format was changed.

# Third-party components and resources

Own code is licensed under AGPL-3.0-only. The external game, Union, Ninja, SDK definitions/import libraries, optional comfort mods and renderers retain their own rights. Their presence in a private test installation does not grant redistribution rights.

The supported development profile uses Gothic II DNdR 2.6-fix/LAA, Union 1.0m and Ninja 4.1.16. Quickloot 1.9.5 and Sprint 2.4.0 use locally prepared bridge revision 1; Toolkit 16.0 and PatchMenu 1.1.1 are separately obtained. No full foreign script/archive is included. The own preparation tool transforms only known local inputs and preserves originals.

External build SDK reference: GothicCoop commit `0255381eeb86ea4b888f420fafaa4a10ee4d85e3`; only separately supplied API definitions/libraries are compiled, not that project's co-op gameplay implementation. See [dependencies](docs/DEPENDENCIES.md).

Character profiles refer to existing game resources examined in the local installation. No original or Velaya texture/model/dialogue/audio files are distributed. The active alpha has no custom start-screen artwork. Source publication is constrained by an explicit allowlist and synthetic fixture hashes.

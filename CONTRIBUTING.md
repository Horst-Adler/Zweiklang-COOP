# Contributing

Use English for public issues, pull requests, documentation and new technical identifiers. English/German plugin text belongs in `src/OreboundCoop/localization/ui.json`; do not hard-code user-facing strings in gameplay code. Polish/Russian are planned for the full version.

Preserve host authority, confirmed inventory decisions, bounded queues and local-player ownership. Never replace safeguards with unconditional success or claim native acceptance from a simulated test. Keep original games, SDKs, foreign archives, real save/log data and the private work website out of commits.

Build/test the affected paths, run the publication audit and describe behavior, evidence and remaining native tests. Preserve legacy save/journal identifiers unless a separately tested migration explicitly replaces them. Report your game/Union/Ninja versions, optional profile and UI language; redact personal data before sharing diagnostics.

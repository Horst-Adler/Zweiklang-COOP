# Third-party provenance

The source in this directory is the own Orebound Co-op implementation, previously developed as Zweiklang COOP. It uses separately supplied Union/ZenGin API definitions and Windows platform libraries; it does not compile the reference project's cooperative gameplay implementation.

See the repository's [third-party notices](../../THIRD_PARTY.md), [dependency catalogue](../../docs/DEPENDENCIES.md) and [build instructions](../../BUILDING.md) for the examined versions, external SDK reference and distribution limits. No original game resources, external SDK or foreign Union menu script are included here. Existing copyright notices and licenses remain applicable.
